# GliterBox — E-Commerce Website

GliterBox is a modern and responsive e-commerce website designed for browsing fashion and lifestyle products. The project focuses on creating a clean, visually appealing shopping experience using HTML, CSS, and JavaScript.

The website organizes products into multiple categories, making it easy for users to explore different collections and navigate through the store.

## Features

* Product Categories — Browse products across multiple categories including:

  * Clothes
  * Jewellery
  * Bags
  * Shoes
  * Sunglasses
  * Hair & Beauty
  * New Arrivals

* Responsive Design — Designed to provide a consistent browsing experience across different screen sizes.

* Modern User Interface — Clean layouts, product-focused sections, and visually appealing styling.

* Category Navigation — Dedicated pages for different product categories for easier browsing.

* Shopping Experience — Dedicated bag/cart page for managing the shopping flow.

## Technologies Used

| Technology | Purpose                                            |

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Nag28102004/gliterbox-eshoping-website.git
```

### 2. Navigate to the Project

```bash
cd gliterbox-eshoping-website
```

### 3. Run the Website

This is a frontend project, so no backend setup or package installation is required.

Open the following file in your browser:

```text
index.html
```

For development, you can also use the Live Server extension in Visual Studio Code.
